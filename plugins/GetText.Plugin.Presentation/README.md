# スライドの記録 (Presentation Capture)

オンライン会議や発表で映しているスライドを、変わるたびに画像で残し、止めたら PowerPoint の PPTX にまとめます。

1. ホームの「スライドの記録」、またはコマンドの一覧 (Ctrl+K / ⌘K) の「スライドの記録を始める」を押します。
2. スライドを映している画面か窓を選びます。
3. 発表が終わったら、タイルの ✕ か「スライドの記録を止めて PPTX に保存」で止め、保存先を選びます。

## 残し方

- 画面が止まった (続けて見たコマが似ている) ときだけ残します。動画・アニメーション・スクロールの途中は残しません。
- 直前に残したスライドと同じなら残しません (画像の指紋 pHash で比べます)。
- 「新しいスライドとみなす変化」: 厳しめ (大きく変わったときだけ)・普通・ゆるめ (箇条書きが 1 行増えたくらいでも残す)。
- 画面が一色で写るとき (保護された動画の配信・隠れた窓など) は残さず、知らせるだけです。保護を回避することはしません。

## 保存とプライバシー

- 画像は、この PC の拡張機能のフォルダ (`plugins/.data/gettext.presentation/sessions/`) と、選んだ PPTX の保存先にだけ書きます。インターネットには送りません。PPTX に保存できたら、フォルダの画像は消します (保存しなかったときは残します)。
- PPTX は GetText が直接書きます (PowerPoint などは要りません)。各スライドに画像を 1 枚、縦横の比を保って置きます。

要求されるアクセス: 画面の画像・選んだファイル・自分のデータの保存・知らせ
