# 文書の文字の読み取り (Document OCR)

PDF (スキャンした書類など) や画像のファイルの文字を読み、テキスト (.txt)・Markdown (.md)・JSON (.json。行の位置つき) に書き出します。

- コマンドの一覧 (Ctrl+K / ⌘K) の「PDF・画像の文字を読む (ファイルを選ぶ)」: いくつかのファイルを選んで読みます。
- 「フォルダの PDF・画像の文字をまとめて読む」: フォルダの中の PDF・画像をまとめて読みます (中のフォルダは見ません)。
- 書き出す先のフォルダを選ぶと、ファイルごとに「元の名前.txt」などを書きます (同じ名前があれば「(2)」を付けます)。
- 読んでいる間は右下に進み具合が出て、「中止」でやめられます。読めなかったファイルがあっても、ほかのファイルは続けます。

## しくみ

- PDF のページは、OS の標準の部品 (Windows: Windows.Data.Pdf、Mac: PDFKit) で画像にしてから読みます。読める画像は PNG・JPEG・BMP・GIF・TIFF・HEIC など (OS による)。写真の向き (EXIF) も合わせます。
- 読み取りは GetText で選んでいる方式 (AI OCR・Windows OCR・Mac の文字認識) で、この PC の中で行います。インターネットには送りません。
- パスワードのかかった PDF は読めません (パスワードを外してから読んでください)。
