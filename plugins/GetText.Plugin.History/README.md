# 読み取りの履歴 (OCR History)

読み取りの画面が読んだ文字をこの PC に保存して、あとからコマンドの一覧 (Ctrl+K / ⌘K) で探せるようにします。
見つかったものを押すと、その回に読んだ文字をコピーします。

## 既定は保存しません

入れただけでは何も保存しません。次のどれかで始めたときだけ保存します。

- 読み取りの画面の 表示 ▾ →「読み取りの履歴」(読み取りの画面で使う機能なので、ホームのタイルにはしていません)
- コマンドの一覧の「読み取りの履歴の保存を始める / 止める」
- 設定 → 拡張機能 → 読み取りの履歴 → 設定 の「読み取った文字を履歴に保存する」

## プライバシーの設定

| 設定 | 既定 |
| --- | --- |
| 保存しておく期間 (これより前は自動で消す) | 7 日 |
| 保存しないアプリ (読み取りの範囲の下のアプリ) | 1Password・KeePass・KeePassXC・Bitwarden・Dashlane |
| この言葉を含むときは保存しない | なし |

- 「読み取りの履歴をすべて消す」で、いつでもすべて消せます (確かめの画面で「すべて消す」を選んだときだけ消します)。
- 保存期間を短くすると、過ぎた履歴はすぐ消えます。続けて画面が変わった後に止まった最後の画面も、少し待ってから保存します。
- 前と同じ文字は保存しません。続けて保存するのは 2 秒に 1 回までです。
- 保存先は、この PC の拡張機能のフォルダ (`plugins/.data/gettext.history/history/`) です。日ごとの JSON Lines のファイルです。
- 読み取った文字はインターネットに送りません。ログにも書きません。拡張機能を消すと、履歴も消えます。

要求されるアクセス: 読み取った画面の文字・自分のデータの保存・知らせ
