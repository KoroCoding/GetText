# キーワードの見張り (Keyword Monitor)

読み取りの画面が読んだ文字に、決めた言葉が出たら、GetText の画面の右下に知らせます (音も鳴らせます)。

- 設定 → 拡張機能 → キーワードの見張り → 設定 で、見張る言葉を 1 行に 1 つ書きます。
- ホームの「キーワードの見張り」のタイル、またはコマンドの一覧 (Ctrl+K / ⌘K) の「キーワードの見張りを始める / 止める」で始めます。
- 全角・半角、大文字・小文字、空白の違い (OCR が入れる「締め 切り」の空白など) は無視します。
- 画面に出たままの言葉は何度も知らせません。消えてまた出たとき、または決めた時間 (既定 30 秒) を過ぎたときだけ、もう一度知らせます。
- 読み取りの画面を開いている間だけ動きます。見張っていないときは、読み取った文字を受け取りません。

## プライバシー

読み取った文字は、知らせに出すだけで、保存もインターネットへの送信もしません。ログにも言葉や文は書きません。

要求されるアクセス: 読み取った画面の文字・知らせ・自分のデータの保存 (見張る言葉の設定)
