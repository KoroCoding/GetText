# 訳を重ねる (Translation Overlay)

読み取りの枠の中の外国語の行に、日本語の訳を、その行の位置に重ねて出します。

- ホームの「訳を重ねる」のタイル、またはコマンドの一覧 (Ctrl+K / ⌘K) の「訳を画面に重ねる / やめる」で切り替えます。
- 読み取りの画面を開いている間だけ動き、閉じると消えます。重ねた文字の上でもクリックは下の窓に通ります。
- かな (ひらがな・カタカナ) を含む行は日本語とみなして訳しません。長い訳は、行の四角に収まるまで小さくします。
- 重ねた文字は GetText の読み取りには写りません (自分の訳を読み直さない)。

## プライバシー

- 訳は、この PC の中の翻訳モデル (FuguMT・NLLB-200) だけで行います。読み取りの画面でオンラインの翻訳を選んでいても、ここでは送りません。
- 翻訳のモデルが入っていなければ使えません (設定 → モデルとセットアップ)。
- 読み取った文字・訳は保存せず、ログにも書きません。

要求されるアクセス: 読み取った画面の文字・知らせ・自分のデータの保存 (オン / オフ)
