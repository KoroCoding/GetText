# QR コード・バーコード (QR / Barcode)

画面の範囲を選ぶと、その中の QR コード・バーコードを読んでクリップボードにコピーします。

- ホームの「QR コード・バーコード」のタイル、またはコマンドの一覧 (Ctrl+K / ⌘K) の「範囲を選んで QR コード・バーコードを読む」を押し、範囲を選びます (Esc でやめる)。
- 読めるもの: QR コード・データマトリックス・Aztec・PDF417・JAN (EAN)・UPC・Code 128・Code 39・ITF・NW-7。いくつあってもまとめて読みます。
- 中身が URL (http・https) のときは、知らせに「開く」が出ます。**自動では開きません**。開く前に、知らせに出たアドレスを確かめてください。

## プライバシー

- 読むのはこの PC の中です。画像は保存せず、インターネットにも送りません。ログにも中身を書きません。
- 読み取りには ZXing.Net (Apache-2.0) を使います (この拡張機能の中だけ)。

要求されるアクセス: 画面の画像・クリップボード・知らせ
