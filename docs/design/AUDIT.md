## 画面ごと

### ホーム (HomeWindow)
- 主な作業: 使う機能を開く。副: 設定・終了・最小化の設定
- ✕ 3 枚の大きなカードに「開く / 前に出す」「閉じる」のボタンが並び、同じ形のボタンが 6 つ。カード全体は押せない
- △ アプリのアイコン (ICO) が 32px に縮小されてにじむ。説明文が長く 2 行に折り返す
- △ 「開いています」のチップは緑の文字 (#15803D) に薄い緑の背景 (コントラスト約 4.3)
- 最近使ったもの (議事録) が見えない。機能が増えたときの置き場所が無い

### 読み取りの結果 (TextWindow)
- 主な作業: 枠の中の文字を見る・コピーする。副: 一時停止・今すぐ読み取る・蓄積・議事録・設定
- △ 幅 540 未満では操作バーの文字が消え、アイコンだけになる (蓄積 = 時計のアイコンで意味がわからない)
- △ 下の右に「AI OCR ・ GPU」「ローカル (GPU ・ 48 ms)」のチップが常に出て主張が強い
- △ AI OCR を使えないときの知らせが状態の文字に埋もれる
- 検索・まとまり (枠) ごとの表示が無い (名簿のような枠の中の文字が上から順に混ざる)

### 読み取り枠 (CaptureWindow)
- ○ 青い枠と上のバー。一時停止で色が変わる (文字でも「停止中」と出る)
- △ 色 (#2B6CB0) と字体 (Segoe UI Symbol・Segoe MDL2) を直接指定。ブランドの印が無い

### 設定 (SettingsWindow)
- 主な作業: 設定を変える。副: セットアップ・フォルダを開く
- △ 6 つのタブ (読み取り・翻訳・表示・議事録・ショートカット・セットアップ・情報)。「表示」に見た目と窓の動きが混ざる。プライバシー (何を外に送るか) の置き場所が無い
- △ 検索が無い。タブを番号 (0〜5) で開いている (並べ替えると別のページが開く)
- ✕ 「フル 約 9GB・標準 約 5GB」はセットアップの実際 (約 8GB・約 4GB) と違う
- △ 「セットアップ・情報 ●」の ● が何を意味するか書いていない
- Mac: ダークで 3 つめの行の右端がそろっていない

### 議事録 (MinutesWindow)
- ◎ 情報は多いが整理されている (上: 取り込み元と記録、中: 発言と話者、下: 操作)
- △ 色の直書き (★ の #E8A200、状態の印の #808080 など)。字体の直書き (Consolas, Yu Gothic UI)

### 画面の録画 (RecorderWindow)
- ○ 選ぶ → プレビュー → 録画、の順で迷わない
- △ 警告の赤 (#C42B1C)・録画中の点 (#DC2626) の直書き。注意書き 3 行が常に出る

### ダイアログ (KeyDialog・SetupDialog・キーの変更・議事録のダイアログ)
- ○ Fluent の部品を使っている。△ 余白と文字の大きさが画面ごとに違う

## 直す方針 (この変更)
1. デザイントークン (`DesignTokens.cs`): 色・文字・余白・角の丸みを意味の名前で 1 か所に。Windows は Fluent 2、Mac は HIG の値。コントラストは単体テストで確かめる
2. 意味の名前のアイコン (`AppIcons.cs`): Windows は Segoe Fluent、Mac は線で描いた記号に置き換える。拡張機能は名前か確かめた SVG の線だけ
3. コマンドの一覧 (Ctrl+K / ⌘K) と登録先 (`Commands.cs`)。機能の一覧 (`FeatureInfo`) からホームを描く
4. ホームを「GetText Hub」に (検索・設定、すぐ使う操作、機能の一覧、最近の議事録)
5. 読み取りの結果: 操作バーを 3 つのまとまり (一時停止・今すぐ / 検索・表示 / 手前に固定・その他) に。Ctrl+F の検索 (枠の上にも印)・まとまりごとの表示
6. 設定: 一般 / 機能 / 拡張 / 詳細 の分類と検索
7. エラー・読み込み中・空の状態をその場の帯で (MessageBox は止める必要があるときだけ)
8. CI で Windows・Mac のライト / ダーク、拡大率 100〜200% の画面を描いて残す
