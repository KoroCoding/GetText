# 拡張機能の安全 (security)

## はじめに: 拡張機能は「囲い」の中では動かない

拡張機能は GetText と **同じプロセス・同じ権限** で動きます。ファイル・ネットワーク・画面など、GetText ができることは拡張機能もできます。
`plugin.json` の `permissions` (画面の「要求されるアクセス」) は **申告** であり、GetText が制限するものではありません。画面にもそう書いています。

だからこそ、GetText は次のことをします。

## GetText が確かめること

| 段階 | 確かめること |
| --- | --- |
| 一覧を読む | https だけ。10 秒で時間切れ、4 MB まで。形の違う項目・SHA-256 の無い項目・`..` を含むファイル名は読み飛ばす。取れなければ前に保存した一覧を使う |
| ダウンロード | https だけ。一覧の大きさを超えたら止める。一覧の SHA-256 と一致しなければ入れない |
| 展開 | `..`・絶対パス・ドライブ・予約名・シンボリックリンク・同じ名前・ZIP 爆弾 (合計・1 ファイル・数・圧縮率) を拒む。すべて確かめてから作業用のフォルダに展開し、最後に移す |
| マニフェスト | 必須の項目・id の形・SemVer・知らない permissions・入口の DLL がパッケージの中にあるか。Plugin API・GetText の版・環境が合うか。依存がそろうか (循環も) |
| 読み込み | 拡張機能ごとの AssemblyLoadContext。入口の DLL がそのフォルダの外なら読まない。`Initialize` の例外では登録したものを全部外す。コマンドの名前の絵文字は拒む |
| 動いている間 | コマンド・タイルの状態・知らせ・読み取りの結果の処理の例外は、GetText の中で受け止めてログと知らせに出す。読み取りの結果は別のスレッドで渡し、遅い拡張機能の分は飛ばす |
| 落ちたとき | 読み込みの前に印を書く。次の起動で印が残っていれば、前の版に戻すか止める。`--safe-mode` で拡張機能なしで起動できる |
| 終わるとき | 1 つにつき 2 秒で待つのをやめる |
| URL を開く | `IPluginUi.OpenUrl` は http・https だけ (ユーザー名入り・file:・独自のスキームは開かない) |
| エクスプローラー / Finder | 引数は 1 つずつ渡し、シェルの文字列にしない |

## 信頼の印

| 印 | 意味 |
| --- | --- |
| 公式 | GetText の開発元の鍵で、パッケージの署名を確かめたもの (`gettext.` の id だけ)。または、GetText の配布物に同梱された公式の拡張機能 (同梱の一覧の SHA-256 と一致。配布物そのものが根拠) |
| 確認済み | GetText が信頼する発行元の鍵で署名を確かめたもの (その発行元の id だけ) |
| コミュニティ | それ以外 (署名が無い・知らない鍵・ほかの発行元の id)。入れる前に注意を出す |

SHA-256 は「一覧と同じファイルか」を確かめるだけで、だれが作ったか (発行元) は確かめられません。そのため、オンラインの一覧の SHA-256 と一致しただけ、一覧に `verified` と書かれているだけでは、公式・確認済みにしません。
署名が付いていて中身と合わないパッケージ (書き換えられた・壊れた) は、入れません。仕組みと鍵の扱いは [PLUGIN_SIGNING.md](../security/PLUGIN_SIGNING.md)。

署名を確かめても、拡張機能は GetText と同じ権限で動きます (囲いの中ではありません)。署名は「だれが作ったか」を確かめるもので、「安全か」を確かめるものではありません。
GetText 本体の署名 (Authenticode・公証) は [SignPath](../SIGNPATH.md) の準備ができてから行います。

## データとプライバシー

- 既定で通信しません。拡張機能の一覧は「オンラインで探す」「更新を確認」を押したときだけ読みます (送る情報はありません)。
- インターネットを使うと申告している拡張機能は、画面に「オンライン」と出し、設定 → プライバシー に名前を出します。
- 拡張機能のデータは `plugins/.data/<id>/` に分けて置き、消すときに一緒に消します。
- ログ (`plugins.log`) には読み取った文字・訳・議事録の文・キーを書きません。利用者名と key / token / password らしい文字列は伏せます。
- テレメトリはありません。アカウントも要りません。

## 守れないこと

- 悪意のある拡張機能が、申告していないことをするのは止められません (同じプロセスで動くため)。信頼できる発行元のものだけを入れてください。
- 拡張機能が自分で持ち込んだネイティブの部品 (DLL) の安全は、GetText では確かめられません。
