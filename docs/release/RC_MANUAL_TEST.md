# Release Candidate の手での確認 (Manual RC Validation)

- 対象: ブランチ `plugin-platform-rc` (コード: `0479726`。この文書を足したコミットは文書だけ)
- 自動の確認 (CI): Windows・Mac の単体テスト・公式の拡張機能 5 つのパッケージ・画面の画像・UI の自己テスト (最新の結果は CI で確かめる)
- 「訳を重ねる」は拡張機能から読み取りの画面の機能に移した (表示 ▾ → 訳を画面に重ねる)。「キーワードの見張り」「読み取りの履歴」はホームのタイルではなく、読み取りの画面の 表示 ▾ で切り替える
- 目的: main に merge する前に、CI では確かめられない **実際の操作** を確かめる
- この確認の間は、新しい機能・リファクタリング・見た目の変更をしない

## 記録の決まり

各項目の「結果」に、環境ごとに次のどれかを書きます。

| 結果 | 意味 |
| --- | --- |
| **PASS** | 期待結果をすべて満たし、失敗条件に 1 つも当たらない |
| **FAIL** | 失敗条件のどれかに当たった (再現の手順・スクリーンショット・`plugins.log` の該当行を「メモ」に) |
| **BLOCKED** | 環境が無くて試せない (理由を「メモ」に。例: モニターが 1 台・PowerPoint が無い・SAC で起動できない) |
| **NOT TESTED** | まだ試していない (初めの状態) |

- **★ = 重要項目**。判定の条件に入ります (下の「判定」)。
- 記録には、トークン・パスワード・個人の文書の中身を書かないでください。スクリーンショットも同じです。
- `plugins.log` を貼るときは、該当の行だけにします (読み取った文字・トークンは書かれない作りですが、念のため確かめる)。

### 判定

- **READY FOR MAIN**: ★ の項目がすべて (Windows と Mac の両方。Mac に無い項目は Windows だけ) **PASS** で、★ 以外にも **FAIL** が無いとき**だけ**。
- ★ の項目に FAIL・BLOCKED・NOT TESTED が 1 つでもあれば **NOT READY** (main に merge しない)。
- ★ 以外の BLOCKED は、理由を書いて残してよい。

### FAIL のとき

FAIL が出た項目だけ、次の順に進めます (新しい機能・見た目の変更はしない)。

1. **再現**: 最小の手順で 2 回再現する
2. **Root Cause Analysis**: 原因 (確定 / 仮説) を、コードの場所と一緒に書く。症状を隠す直し方 (検査を弱める・テストを消す・待ち時間を延ばすだけ) はしない
3. **修正**: 原因を直す最小の変更
4. **Regression test**: その項目の失敗を再現する単体テスト (または CI の UI の自己テスト) を足し、直す前に落ち、直した後に通ることを確かめる
5. **再確認**: CI (Windows・Mac) が成功し、その項目を手でもう一度確かめて PASS にする

記録の書き方:

```
### FAIL: <項目の番号と名前> (<環境>)
- 症状:
- 再現の手順:
- 原因 (確定 / 仮説):
- 修正 (コミット):
- 追加した regression test:
- 再確認 (CI の実行・手での結果):
```

### P3. 拡張機能のテスト用のパッケージ (v1・v2・壊れた v3)

項目 12〜17 で使います。見本の拡張機能 (`gettext.sample`。配布物には同梱しない) から作ります。
GetText のソースのフォルダで、Windows PowerShell で実行します (.NET 9 SDK が必要):

```powershell
powershell -ExecutionPolicy Bypass -File tools\make_plugins.ps1 -Out rc-test\plugins
Add-Type -AssemblyName System.IO.Compression, System.IO.Compression.FileSystem
function New-TestVersion([string]$src, [string]$dst, [string]$version, [string]$type) {
    Copy-Item $src $dst -Force
    $zip = [IO.Compression.ZipFile]::Open($dst, 'Update')
    try {
        $entry = $zip.GetEntry('plugin.json')
        $reader = New-Object IO.StreamReader($entry.Open()); $json = $reader.ReadToEnd(); $reader.Close()
        $json = $json -replace '"version":\s*"1\.0\.0"', ('"version": "' + $version + '"')
        if ($type) { $json = $json -replace '"type":\s*"[^"]+"', ('"type": "' + $type + '"') }
        $entry.Delete()
        $writer = New-Object IO.StreamWriter($zip.CreateEntry('plugin.json').Open(), (New-Object Text.UTF8Encoding $false))
        $writer.Write($json); $writer.Close()
    } finally { $zip.Dispose() }
}
$v1 = 'rc-test\plugins\gettext.sample-1.0.0.gtplugin'
New-TestVersion $v1 'rc-test\gettext.sample-2.0.0.gtplugin' '2.0.0' $null
# 壊れた v3: 入口の型が無い (パッケージの検査は通り、読み込みで失敗する)
New-TestVersion $v1 'rc-test\gettext.sample-3.0.0-broken.gtplugin' '3.0.0' 'GetText.Plugins.Sample.Missing'
Get-ChildItem rc-test -Recurse -Filter 'gettext.sample-*.gtplugin' | Select-Object Name, Length
```

- 拡張機能の置き場所: Windows `%LOCALAPPDATA%\GetText\plugins\`、Mac `~/Library/Application Support/GetText/plugins/`。記録は `plugin-state.json`、ログは `logs\plugins.log`。

## 1. 通常の読み取り (OCR) ★

- **準備**: P1・P2。読み取りの方式 (OCR エンジン) を既定の「AI (PP-OCRv6・高精度)」のままにする。翻訳はローカル (FuguMT が入っていること)。
- **操作**:
  1. ホームの「文字の読み取り」を開く。
  2. 読み取り枠を付録 A の「A-1 英語と日本語」の上に重ねる。
  3. 5 秒待つ。F5 (今すぐ読む) を押す。Ctrl+P で一時停止し、もう一度 Ctrl+P で再開する。
  4. 方式を Windows OCR (Mac は Vision) に変えて、もう一度読む。
- **期待結果**:
  - 原文の欄に A-1 の 4 行が出る (読み間違いは 1 行に 1 文字まで)。英語の行には日本語訳が付く。
  - 一時停止中は枠がオレンジ色で「停止中」と出て、文字が更新されない。再開すると読み取りに戻る。

- **失敗条件**: 文字が出ない・10 秒以上待たされる・行が抜ける / 順序が違う・訳が付かない・一時停止が効かない・GetText が落ちる / 固まる。

## 2. Ctrl+F の検索 ★

- **準備**: 項目 1 の状態で、付録 A の A-1〜A-2 が枠の中に入っている。
- **操作**:
  1. Ctrl+F (⌘F) を押し、`keyword` と入れる。
  2. Enter・F3 で次へ、Shift+Enter (Shift+F3) で前へ移る。
  3. `締め切り` で探す。続けて、無い言葉 `zzzz` で探す。
  4. Esc で閉じる。
- **期待結果**:

  - `締め切り` は日本語でも一致する。`zzzz` は一致が無いことが分かる表示になり、印が消える。

- **失敗条件**: 一致の数が違う・移動の順が画面の順と違う・Esc の後も印が残る・入力中に固まる。

  4. (できれば) DRM のある動画の配信を再生し、枠に入れる。
- **期待結果**:
  - 1: 原文の欄に「画面が黒く写っています」と、保護を回避しない旨の説明が出る。
  - 2: 「枠の中に文字が見つかりません」になる (保護とはみなさない)。
  - 3: 黒い画面は残さず、知らせを **1 回だけ** 出す。S1 は普通に残る。
  - 4: 1 と同じ知らせになる。GetText は保護を回避しない (黒いまま)。
- **失敗条件**: 黒い画面で知らせが出ない・白い画面を保護とみなす・黒い画面をスライドとして残す・知らせを何度も出す・保護された中身が写る。
- **結果**: Windows: NOT TESTED / Mac: NOT TESTED

## 21. 複数のモニター

- **準備**: モニターを 2 台。できれば拡大率を変える (例: 1 台目 100%・2 台目 150%)。2 台目を 1 台目の **左** か **上** に置く (座標が負になる配置)。
- **操作**:
  1. 読み取り枠を 2 台目に動かし、付録 A を読む。Ctrl+F で `keyword` を探す。
  2. 枠を 2 台の境目にまたがせて読む。
  3. 2 台目にマウスを置いて Quick OCR (Ctrl+Alt+Q) で A-1 を囲む。
  4. 2 台目で訳を重ねる (項目 7)。
  5. スライドの記録で 2 台目の画面を選んで、S1・S2 を記録する。
- **期待結果**:
  - 1: 読めて、印が語の上に合う。
  - 2: 落ちずに読める (またいだ部分も読める)。
  - 3: 案内が 2 台目に出て、囲んだ所の文字がコピーされる。
  - 4: 訳が 2 台目の行の位置に合う。
  - 5: 2 台目の中身だけが残る。
- **失敗条件**: 2 台目で読めない・印 / 訳 / 囲む範囲が別の場所にずれる・別のモニターを写す・落ちる。
- **結果**: Windows: NOT TESTED / Mac: NOT TESTED

## 22. 拡大率 125・150・200% ★

- **準備**: Windows: 設定 → システム → ディスプレイ → 拡大/縮小 を 125% にし、サインアウトしてサインインし直す。Mac: 外部モニターと Retina の内蔵画面の両方 (「解像度」を変えて 2 種類)。
- **操作** (125%・150%・200% のそれぞれで):
  1. 項目 1 (読み取り)・項目 3 (印)・項目 5 (Quick OCR) を行う。
  2. 項目 7 (訳を重ねる) を行う。
  3. 設定 → 拡張機能・モデルの一覧・ホーム・Ctrl+K を開き、窓をいちばん小さくする。
  4. 項目 9 の 9-1 と 9-9、項目 10 の 1 を行う。
- **期待結果**:
  - 1・2: どの拡大率でも、読める文字・印・訳・囲んだ範囲がずれない (文字 1 つ分以内)。
  - 3: 文字・ボタンが切れない・重ならない。窓をいちばん小さくしても操作できる。
  - 4: PPTX の画像がぼやけたり、拡大率の分だけ大きく / 小さくなったりしない (画面の実際の解像度のまま)。
- **失敗条件**: 拡大率によって印・訳・範囲がずれる・文字やボタンが切れる・PPTX の画像の大きさが拡大率で変わる。
- **結果**:

  | | 125% | 150% | 200% |
  | --- | --- | --- | --- |
  | Windows | NOT TESTED | NOT TESTED | NOT TESTED |
  | Mac (外部 / Retina) | NOT TESTED | NOT TESTED | — |
